# Threads 自動投稿（celeste）

毎日**よく見られる時間帯**に、**AI が書いた投稿文**を Threads に自動投稿します。最初に設定してしまえば、あとは何もしなくて大丈夫です。

**すべて無料で動きます。**
- Threads API：無料
- 投稿文を書く AI：Google Gemini API の無料枠（1日3回の投稿なら十分に収まります）
- GitHub Actions：無料枠の範囲内（Private リポジトリでも月2,000分まで無料。この仕組みが使うのは月750分ほど）

## しくみ

| いつ | 何をする | ファイル |
|---|---|---|
| 毎週月曜 3時ごろ | 過去100件の投稿の閲覧数を時間帯（日本時間）ごとに平均し、上位3つの時間帯を `schedule.json` に保存する | `analyze.py` |
| 1時間おき | 投稿時間帯になっていたら、AI が `persona.md` に沿って文章を書いて投稿する（`posts.txt` に投稿が書いてあれば、そちらを優先） | `post.py` |

- 投稿が10件未満のうちは、定番の **7時・12時・21時** に投稿します。
- 同じ時間帯ばかりにならないよう、毎週1枠は「まだあまり試していない時間帯」をお試しで使います。
- 投稿どうしは3時間以上空けます。深夜（0〜5時）には投稿しません。
- AI は直近15件の投稿を見て、似た内容が続かないようにします。
- 投稿した文章はすべて `posted.txt` に記録されるので、あとから確認できます。

## 投稿の内容を決める（persona.md）
`persona.md` の「アカウントのテーマ」を、自分のアカウントのテーマに書き換えてください。やることはこれだけです。口調や書かないことも、必要なら調整できます。

### 自分で書いた投稿を混ぜたいとき（任意）
`posts.txt` に書いておくと、AI より優先して上から順に投稿されます。投稿と投稿の間は `---` だけを書いた行で区切ります。空のままでも問題ありません。

## セットアップ手順

### 1. Threads のアクセストークンを取得する
1. [Meta for Developers](https://developers.facebook.com/) でアプリを作成し、ユースケースで「Threads API にアクセス」を選びます。
2. 権限 `threads_basic`、`threads_content_publish`、`threads_manage_insights` を追加します。
3. 「役割」→「Threadsテスター」に自分の Threads アカウントを追加し、Threads アプリの「設定 → アカウント → ウェブサイトのアクセス許可」で招待を承認します。
4. 「Graph API エクスプローラー」で Threads のトークンを発行し、**長期トークン（60日有効）** に交換します。

### 2. Gemini の API キーを取得する（無料）
1. [Google AI Studio](https://aistudio.google.com/apikey) に Google アカウントでログインします。
2. 「API キーを作成」を押して、キーをコピーします。**クレジットカードの登録は不要**です。課金（Billing）を有効にしなければ、料金は発生しません。

> 無料枠では、送った内容が Google のサービス改善に使われることがあります。投稿文のテーマ程度なら問題ありませんが、`persona.md` に個人情報は書かないでください。

### 3. GitHub にアップロードする
1. GitHub で新しいリポジトリを作ります（**Private を推奨**）。
2. このフォルダの中身をすべてアップロードします。
3. リポジトリの **Settings → Secrets and variables → Actions → New repository secret** で、次の値を登録します。

| 名前 | 中身 | 必須 |
|---|---|---|
| `THREADS_ACCESS_TOKEN` | 手順1の長期トークン | ✅ |
| `GEMINI_API_KEY` | 手順2の API キー | ✅ |
| `GH_PAT` | トークンの自動更新用。GitHub の Fine-grained token で、このリポジトリの **Secrets: Read and write** 権限を付けたもの | 推奨 |

> `GH_PAT` を登録しない場合、Threads のトークンは60日で期限が切れます。その場合は期限が来る前に、手順1でトークンを取り直して登録し直してください。

4. **Settings → Actions → General → Workflow permissions** で **Read and write permissions** を選んで保存します（投稿済みの文章を記録するために必要です）。

### 4. テーマを書く
`persona.md` の「アカウントのテーマ」を書き換えます（GitHub のサイト上で鉛筆マークから編集できます）。

### 5. 動作確認
1. **Actions** タブで「投稿時間帯の分析とトークン更新」を選び、**Run workflow** を押します。`schedule.json` が更新されれば、Threads API との接続はOKです。
2. 「Threads 自動投稿」を選び、**force にチェックを入れて** Run workflow を押すと、AI が書いた投稿がすぐに1件投稿されます。

ここまでできれば、あとは何もしなくても毎日自動で投稿されます。ときどき `posted.txt` やThreadsで投稿を見て、気になる点があれば `persona.md` を調整してください。

## よくある調整

- **投稿回数を変える**：`analyze.py` の `POSTS_PER_DAY` を変更します。
- **一時停止する**：Actions タブ →「Threads 自動投稿」→ 右上の「…」→ **Disable workflow**。

## 注意
- GitHub Actions の定期実行は、混雑していると数十分遅れることがあります。予定時刻から2時間以内なら投稿されるようにしてあります。
- Gemini の無料枠の上限は Google の都合で変わることがあります。上限に達した場合は1時間後にもう一度試し、それでもだめならその回の投稿は見送られます。
- AI が書いた文章は、事実と違う内容を含むことがあります。
- 無料枠を超えないよう、この仕組み以外で GitHub Actions をたくさん使っている場合は、Settings → Billing で使用量を確認してください。無料枠を超えても、支払い方法を登録していなければ請求はされず、その月の実行が止まるだけです。
